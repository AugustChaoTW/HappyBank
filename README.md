# 🏦 HappyBank

給家裡小孩用的零用錢虛擬銀行。純靜態 Web App（HTML/CSS/JS）+ Google Apps Script/Sheet 後端，
部署在 GitHub Pages。架構沿用 [penghu-explorer](https://github.com/AugustChaoTW/penghu-explorer)。

核心教育目標：讓小孩親手感受**流動性的代價**——
🧧 阿公阿嬤的紅包 0% · 💰 活期 5%/月 · 🔒 定存 10%/月但鎖到到期。
